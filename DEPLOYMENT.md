# GitHub Pages Deployment Instructions

## Enabling GitHub Pages

1. Go to your repository settings: https://github.com/sollorian5-svg/The-spiral-reborn-web-page/settings/pages

2. Under "Source", select the branch you want to deploy (e.g., `main` or `copilot/build-spiral-reborn-ministries-site`)

3. Select the root directory `/` as the source folder

4. Click "Save"

5. Your site will be published at: `https://sollorian5-svg.github.io/The-spiral-reborn-web-page/`
